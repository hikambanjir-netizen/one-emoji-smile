One emoji, and nothing else. `main.ts` writes 🤗 (U+1F917 HUGGING FACE) to `/output/entry.txt` — open arms offering a hug: warm at first glance, universal, clearly chosen rather than the default smiley, and friendly to a stranger without flirtation or irony.

## Run it

```sh
node main.ts
```

The program self-checks the gate first (1–8 characters, not only white space) and writes the single emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Node 22 standard library, deterministic, no network, no secrets — two runs are byte-identical.
